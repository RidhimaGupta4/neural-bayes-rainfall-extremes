# results/draws/

Stan posterior draws (μ, σ, ξ; 4,000 per cell) for the 256 real cells, written by
`R/10_mcmc.R`, `R/10b_refit_flagged.R` and `R/13_export_draws.R`. Not stored in the repository
(about 50 MB); regenerate with those scripts. Used to compute exact posterior SDs and Storm
Desmond's return period in `python/evaluate.py`.
