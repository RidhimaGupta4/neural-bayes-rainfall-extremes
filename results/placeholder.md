# results/

Outputs of the analysis. Main summary: `evaluation.json`.

| File | Contents |
|---|---|
| `evaluation.json` | Simulation metrics, real-cell criteria, held-out results, Storm Desmond, timing |
| `real_comparison.csv` | Per cell: estimator and Stan posterior medians and 90% limits, their difference in Stan posterior SDs, interval width ratio |
| `nbe_sim_seed*.csv`, `nbe_real_seed*.csv` | Estimator posterior quantiles (0.05, 0.25, 0.5, 0.75, 0.95) on simulated and real data, for each training seed |
| `mcmc_sim.csv`, `mcmc_real.csv` | Stan posterior quantiles, SDs and convergence diagnostics, after the refits of Amendment 2 |
| `mle_sim.csv`, `mle_real.csv` | Maximum-likelihood estimates and Wald 90% intervals |
| `jags_check.csv` | JAGS vs Stan on 16 cells |
| `heldout_by_cell.csv` | Each held-out maximum with exceedance indicators and quantile scores for each method |
| `nbe_apply.json` | Prediction timing and the out-of-distribution check |
| `training_seed*.json` | Training settings and the loss history for each seed |
| `mcmc/` | Intermediate Stan output in chunks (see `mcmc/placeholder.md`) |
| `sim/` | Simulated test set, regenerated by a script (see `sim/placeholder.md`) |
| `draws/` | Stan posterior draws, regenerated by scripts (see `draws/placeholder.md`) |
